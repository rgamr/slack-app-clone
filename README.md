# Slack Clone

A real-time chat application inspired by Slack, built with modern web technologies. *(Note: This project was built by following along with a tutorial by Code with Antonio.)*

## 🚀 Live Demo
[https://slack-app-clone-eight.vercel.app]

## 🛠️ Technologies Used
- **Framework:** Next.js
- **UI Library:** React
- **Backend & Database:** Convex
- **Styling:** Tailwind CSS
- **Components:** shadcn/ui
- **State Management:** Jotai
- **Icons:** Lucide React
- **Authentication:** Convex Auth

## ✨ Features
- Real-time messaging and chat
- Workspaces and channel management
- Direct messaging
- Authentication (OAuth / Email)
- Responsive design
- Message formatting and emojis

## 📦 Getting Started

First, install dependencies:

```bash
npm install
```

Start the Convex development server:

```bash
npx convex dev
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000] with your browser to see the result.
